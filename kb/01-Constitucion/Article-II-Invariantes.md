# Artículo II — Invariantes


Los **20 invariantes** (INV-01..INV-20) agrupados por dominio — reglas innegociables que ningún componente puede violar:

| Grupo | Invariantes |
|-------|------------|
| Model Invariants | INV-01, INV-02, INV-03 |
| Tool Invariants | INV-04, INV-05, INV-06, INV-07 |
| Execution Invariants | INV-08, INV-09, INV-10, INV-11 |
| State Invariants | INV-12, INV-13 |
| Human Interaction Invariants | INV-14, INV-15 |
| UI Invariants | INV-16, INV-17 |
| Observability Invariants | INV-18, INV-19, INV-20 |

**Los más citados por los componentes:** INV-18 (eventos observables), INV-19 (actores/trazabilidad), INV-20 (errores normalizados), INV-08/INV-09 (lifecycle y límites de ejecución).
