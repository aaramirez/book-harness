# Agentes del Harness

Agentes usados para producir el libro dentro del repositorio:

| Agente | Rol |
|--------|-----|
| `book-architect` | Arquitecto del libro — define estructura, planifica capítulos |
| `chapter-author` | Autor de capítulos — escribe cada chapter.md siguiendo las reglas |

Los agentes operan bajo la misma [[Architecture-Constitution|constitución]] que el libro enseña (la constitución gobierna el propio harness).

Fuente: `agents/*.md` — ver también [[06-Harness/Skills|Skills]] y [[06-Harness/Planes|Planes]].
