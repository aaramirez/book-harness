# Skills del Harness

Skills reutilizables del repositorio (en `skills/*/SKILL.md`), que guían a los agentes al producir el libro:

| Skill | Propósito |
|-------|-----------|
| `analyze-constitutional-impact` | Analizar impacto constitucional de un diseño |
| `define-component` | Definir un componente siguiendo el esquema del registry |
| `define-contract` | Definir un contrato (STRUCT/ENUM) canónico |
| `design-retrieval-practice` | Diseñar el retrieval practice de un capítulo |
| `write-pseudocode` | Escribir pseudocódigo validable |
| `write-technical-chapter` | Escribir capítulos técnicos con las 19 secciones obligatorias (1–19, las que verifica `validate-chapter`); el método de aprendizaje activo añade la 0 (preguntas guía), la 20 (lente de sistemas) y la 21 (práctica) |
